Untitled Text

A minimal text layout with crossed section rules, dense type scale, and zero visual noise.
Overview

This layout preserves the structural armature of the original design while enforcing a strict monotone aesthetic. High legibility and zero visual noise ensure that shared texts remain easy to read across devices.

The asymmetric grid aligns section labels to the left of the hairline vertical rule, creating clear visual hierarchy without needing bright highlight colors.

Content

Documents can be split into logical sections using top border dividers that cross the vertical armature line.

Design Highlights

  • Warmer stone grey background (`#EAE8E3`)
  • Selection highlight: original ink color on lemon yellow (`#FFE800`)
  • Native support for Pretendard Variable typography
  • Subtle vertical armature grid line with crossed horizontal section rules
"The details are not the details. They make the design."

For additional pages in your setup, duplicate this structure and simply update the content inside the section blocks.
