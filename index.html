Untitled Text

A minimal multi-page text layout built for long-form reading and seamless sharing.
Overview

This layout preserves the structural armature of the original CV template while enforcing a strict monotone aesthetic. High legibility and zero visual noise ensure that shared texts remain easy to read across devices.

The asymmetric grid aligns section labels to the left of the hairline vertical rule, creating clear visual hierarchy without needing bright highlight colors.

Content

Documents can be split into logical sections using top border dividers and side labels.

Design Highlights

  • Warmer stone grey background (`#EAE8E3`)
  • Selection highlight: original ink color on lemon yellow (`#FFE800`)
  • Native support for Pretendard Variable typography
  • Subtle vertical armature grid line
"The details are not the details. They make the design."

For additional pages in your Firebase setup, duplicate this structure and simply update the content inside the section blocks.
